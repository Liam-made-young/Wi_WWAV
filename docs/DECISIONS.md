# Decisions

Date, choice, reason, and what was turned down. Decisions the founder made in
conversation are marked **Decided** in `docs/SPEC.md`; this file logs the ones
made while building, including every Open item built at its recommendation
before the founder answered (`docs/QUESTIONS.md`).

| Date | Choice | Reason | Turned down |
|---|---|---|---|
| 2026-10-07 | This repository is the desktop repo the spec calls `wi-wwav-desktop` (9.12). | The founder created it for the app. | A second new repository. |
| 2026-10-07 | `formats/` is Mi-WWAV at a pinned commit, as a submodule with a sparse checkout (Open #52 at its recommendation). The sparse paths are `prana/core`, `prana/tools`, `prana/tests`, `prana/hal/native`, `prana/SPEC.md`, `prana/CMakeLists.txt`, `prana/web/src/sim`, `formats/swav`, `wi/src/formats`, `wi/test` and `wi/GATES.md`; `tools/bootstrap.sh` sets them. | The parity tests run the reference tools and PRANA's goldens from their source. This repository is public and Mi-WWAV is private, so nothing from it is copied in. | Copying the four folders in; splitting them into their own repository now. |
| 2026-10-07 | JUCE is pinned at 8.0.15 (`tools/fetch_juce.sh`), newer than WWAV Push's 8.0.4. | 8.0.15 bundles the VST3 SDK 3.8.0, whose licence is MIT (checked in `VST3_SDK/LICENSE.txt`), which is what 9.10 asks to confirm at the version pinned. JUCE itself stays under its commercial (Starter) licence. | 8.0.4, whose VST3 SDK predates the MIT licence. |
| 2026-10-07 | `wwav-ids` keeps MI-WWAV-OS's ULID (monotonic within a millisecond) and also holds the last millisecond when the clock steps backwards. | A clock step back would otherwise mint an id that sorts before the last one, and media names must sort by creation. | Trusting the wall clock. |
| 2026-10-07 | UI tests run in Playwright's Chromium against the web UI with the dev bridge, and the WebKit pass runs through WebKitGTK's own WebDriver (`WebKitWebDriver`, via `tauri-driver`) against the built Linux app. macOS CI adds Playwright's WebKit. | Playwright's WebKit build can't be downloaded in the build environment, and WebKitGTK is the engine Tauri itself uses on Linux, so it is the closer stand-in for WKWebView anyway. A hand pass on a real Mac still covers WKWebView (9.11). | Skipping WebKit until a Mac runner exists. |
| 2026-10-07 | `session.json`'s numbers are I-JSON (RFC 7493): integers that fit in 64 bits, and doubles. An unknown key holding a larger integer reads as a double, so its digits past a double's are lost at the next save. Zero has one form: `-0.0` is written `0.0`. | serde_json keeps such an integer exactly only with its `arbitrary_precision` feature, and Cargo turns a feature on for every crate in the build, so the wire, the store and the app would all get numbers kept as text, compared as text (`1.0` ≠ `1.00`, `-0.0` ≠ `0.0`) and allocated one by one. JavaScript's JSON (PRANA's web tools, Wi) loses the same digits. Writing `-0.0` as `0.0` is what `JSON.stringify` and RFC 8785 do, and keeps the writer in agreement with the journal, whose comparisons call the two equal. | `arbitrary_precision` for the workspace; refusing to open such a file. |
| 2026-10-07 | A `.wwavsession` is open in one place at a time. `Package::open` takes an exclusive lock on `journal/lock` and refuses a second open with "This session is already open in another window." On a filesystem that can't lock it opens unlocked, and each save writes a temporary file with its own name either way. The lock is std's `File::try_lock`, so `wwav-session` needs Rust 1.89 where the workspace says 1.80. | Two windows on one package shared one journal and one `session.json.tmp`: a second window killed mid-save left `session.json` empty, and their joined histories made ⌘Z panic. | A lock crate (`fs4`) or `flock` through `rustix` to stay on 1.80; a lock file outside the package. |
| 2026-10-07 | Send session… names its folder as PRANA's disc writer names a song (the nine characters become spaces, runs of spaces become one, cut to 39 characters, trimmed), but keeps letters in any script and says "Untitled" for an empty title. | PRANA's ASCII-only step and its "Song" are for the device's 47-byte names on a disc of songs; a session folder is shown by the OS and may hold a film. The cut keeps `<Title>.wwavsession.zip.part` under a file name's 255 bytes and paths under Windows' 260 characters. | PRANA's rule exactly; no cut, which made Send fail on a long title. |
